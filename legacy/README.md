# Legacy DTCG JSON exports

These folders contain **Design Tokens Community Group (DTCG)** JSON files exported from Figma before DS 3.0.

They are **superseded** by [`../us-tokens.css`](../us-tokens.css), which is generated directly from the live Figma file and includes fluid `clamp()` values, colour modes, and theme tokens.

Kept for reference and for tools that still consume DTCG JSON. Do not update these by hand — regenerate from Figma into `us-tokens.css` instead.

| Folder | Original role |
|--------|---------------|
| `01. Primitive Tokens/` | Base palette, spacing, typography primitives |
| `02. Color Tokens/` | Semantic colours per mode (Light, Dark, Grey, Color) |
| `03. Document Tokens/` | Layout: page width, margins, grid |
| `04. Number Tokens/` | Component spacing, radii, type scale |
